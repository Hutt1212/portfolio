# TemPad assets

Images in this folder come from the **TVA Classic** device theme by
Arthur_Moss (https://www.reddit.com/user/Arthur_Moss/), inspired by the TVA
TimePad from the *Loki* series:

- `screen.png` — `globalWallpaper-1.png`
- `glyphs.png` — icon column cropped from `desk-2.png`
- `arrow.png` — `itemRightArrow.png`
- `bt1-4.png`, `btc.png` — battery / charging icons
- `bluetooth.png` (`bl2.png`), `playing.png`, `pause.png`

Colours used in the CSS (`#f8861e`, `#29231e`) are from the theme's
`config.json`. The screen font is IBM Plex Mono Light (SIL Open Font License),
shipped with the theme, at `app/fonts/IBMPlexMono-Light.ttf`.
